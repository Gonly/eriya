# 2026-11-06（Day104）· 十一月初六，交割之后，水退了三寸，桶卸在南头

## 今日主线
- 05:00 宿舍：恢复期第十六日，右膝肿、绑布条、暂缓高强度。互报平安第五日（今天只按了星辉石，护身符省了一个）。第五课第一步：把行踪写成「别人能照着走」——日期、路口、停多久、看什么；最难的是「停多久」，因为她自己从不停。给宫磊的话改成：「我画了一张东西给你看，你画得出来就算数。」
- 06:30 食堂：叁正清昨晚回城，今早到库房**交钥匙** →「钥匙交代管，事后归还」中间隔了一夜，钥匙过谁手未知。他回城第一句是问「**昨天谁去过库房门口**」（她只去过水道）。执事助理：「归还簿？不清楚，昨天没人跟着他去还。」
- 07:30 公告栏：初五告示撤了，新纸两行「初五盘点已毕，旧料暂存已清；器物库房照常开用」，落款**还是一道竖、笔压更重、尾巴拖出一小截**（同支笔？）。远处看库房：**门开着，有人在把箱子往里挪**。
- 09:00 城南汤屋：第一次把「第二个人」用上——带 C 级新人跟在身后三十步走自己的路；路线写成四段：汤屋后巷→染坊后墙→旧运铜水道下游木栈道→城南卸桶石槽；三个路口各停一盏/两盏/三盏香。
- 10:30 **突发事件（好事）** 城南下游石槽：木梁上**两只空桶**，桶沿滴水、桶底暗红渣（干铜锈混细砂）；**新人自己看出「桶是空的」**（第二人独立复现成立）；石槽壁留新水线，水线以下有铜锈色湿痕；槽壁走向**朝城墙根部**。她没跟过去。今天没有人看见她。
- 12:00 食堂：补完「取走多少」＝**两桶铜锈水**；推出三层：三十斤＝锈的重量（写在条子上）／真实运走＝整槽的水／**水下面还有东西**。
- 13:00 医棚后院：布罗把「san——」接上「先生」→**叁先生**坐实；补出「三十斤……是锈。锈下面……有水。」老修女：「他说这句时一直看着门口。」→ 布罗怕谁进来。
- 15:00 训练场：第四剑改定桩（不跑、只求收剑不抖）；追踪者：「昨天那剑值几个钱，今天一个钱都不值——**因为你改了目标**。」第四课升级：**路线要交给一个不认得你的人，照着走，别走错**；并补完昨天那句——「他等的可能不是强者，只需要一个每天走过那儿、把看见的东西记下来的人。**他们不威胁你，他们让你看见。**」
- 16:30 归还台：窗口关着、后面没人；柜台上多出**一只扣着的小木桶**，桶底水痕未干（初六还运过水？或大桶被分装？）；桌沿竖划痕**旁又添一道**，两道挨得很近，同一人连签两回。
- 18:00 城南汤屋：摊主第二次出手但**不说话**，把一块**被咬过的铜片**（绿得发暗，边缘一排牙印）放在她碗边。她收下但没去找任何东西（追踪者明令先别去找它）。
- 19:00 城墙石阶：追踪者今天**没先问她昨天在哪儿**；评「三件做对了：带第二个人、没跟上去、**没去问摊主**」——「不知道该问什么的时候，别问。」铜片摸过咬痕：「这兽还在收集铜，而这个人把它咬过的东西送到你碗边。」补完：老头那一下没追她，是**让她看清了脸才走的**。
- 21:30 宿舍·通讯石：口述改成念**路**（含三处停顿时长）。「宫磊，我不等了。『铜最后变成了什么』我等了你三天，我不问了。我改问一个别的——你能照着我念的，画一张出来吗？画得出来，就算数。」三行给他：桶是空的／卸在城南石槽／水从槽底走地下往城墙根。枕边：被咬过的铜片＋护身符＋纸条。

## 线索与目标推进
- **叁先生正式坐实（新）**：布罗梦话「san——先生」；叁正清回城即清点「昨天谁去过库房门口」。
- **初五交割落地**：两桶铜锈水，卸在城南石槽；「三十斤」是锈的重量，锈下面另有东西。
- **行踪复现（机制化）**：第二人复现第一次用在行踪上（新人独立判断出「桶是空的」）；第四课升级为「交给不认得你的人照着走」。
- **摊主立场再升**：从「今天的水，别去碰」到递上被咬过的铜片——他在喂它铜，或在拿饵的结果找她。
- **归还台新物**：初六柜台上扣着一只小木桶，底有水痕 → 仍有人运水，或大桶被分装。
- **签名链**：新告示落款仍是一道竖、笔压更重；三处竖仍与「两条横一道竖」那族严格分开。
- **钥匙时间线**：初五整日代管 → 昨夜钥匙在代管人手上 → 今早交回；归还簿无人见证归还。
- **风险**：反跟踪规则今日全部做到（带第二人/不重复路线/不问摊主/不跟任何人），但城内压力从「被记住」转向「被清点」。
- **约束**：追踪者明令先别去找小家伙 → 今日只收铜片，未接近。
- **剑术**：第四剑定桩，收剑不抖；右膝仍肿，暂缓高强度。

## 🌙 Day104 摘要
阴转多云，午前薄雾，霜没结；旧运铜水道水位比昨日低三寸，铜屑退成一层暗红薄膜。
今天她做对了追踪者第五课真正要的那件事：带 C 级新人走了一遍自己的路，在城南石槽，新人自己看出「桶是空的」——第一次，她的事被第二个人独立重走了一遍。而这一天没有人看见她。
布罗把「san——」接成「先生」，正式坐实叁先生，还补出「三十斤是锈，锈下面有水」。归还台柜台上多出一只扣着的小木桶，叁正清回城第一句是问「昨天谁去过库房门口」，汤屋摊主递来一块被咬过的铜片。
追踪者补完了那句话：如果有人在等一个人看见后院那片绿——他们不威胁你，他们让你看见。
夜里她对通讯石说：宫磊，我不问你那个问题了，我等了你三天，我不问了。我改问一个别的——你能照着我念的，画一张出来吗。
