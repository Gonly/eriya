# 2026-11-05（Day103）· 十一月初五，交割日，水真的在涨

## 今日主线
- 05:00 宿舍：恢复期第十五日，零绷带。互报平安第四日（星辉石＋护身符都按了）。追踪者把表还回来，四列：**初几／几点／谁来／谁能证明**。她自己誊了一份**空表**——只抄结构不抄答案，准备找一个跟此事无关的人独立填。护身符纸条归位（四折塞回最里层）；铜牌背面那道**一道竖**的划痕在灯下反光。登记是哪一年发的那串铜牌，她还是想不起来。
- 06:30 食堂·执事助理：**叁保管员今天整天没来**（不是半日假）；器物库房照旧不开，「盘点未完，旧料还在往外挪」。她追问旧料交给谁签收 →「照规矩该叁本人签，他告假了，就走**代管**」。→ **代管＝文书房「代」字底下那三个被刮的名字**。老伯也认出她就是昨天扫地的姑娘。
- 07:30 公告栏（走明路第三天，特意绕弯）：铜镇纸被挪到纸的左下角，**露出落款——没有名字，只有一道竖**。告示正文：「器物库房初五停用一日，盘点未完，旧料移出暂存；**钥匙交代管，事后归还**。」→ 库房钥匙今天不在叁正清手上；**告示落款的竖＝护身符铜牌的竖＝同一族（一个人），而纸条的「两条横一道竖」是另一族**，三者不混为一事；镇纸底下的铜面比别处绿得深。
- 09:00 城南汤屋：把誊好的**空表**推给C级新人（「你昨天从哪条路走过来、几点、看见谁，就照你记得的写」），新人写完反问「这有什么用」→**第二个人画出来的表诞生**。两张并排：「布袋被取走」一格上第一次出现两个互不相识的人写下的同一个意思（她的「每月初一」／新人的「初一，见过一次」）→**第四列「谁能证明」开始起作用**。随后去城北料行侧门外三十步远看：侧门关着，门槛外有一小片**新的还没干的水渍**。
- 10:30 **突发事件（遭遇）** 旧运铜水道第三个取料口（栅栏被细齿锯开处）外的堤上：**水真的在涨**，铜锈色水一段段漫上碎石，水面浮着一层细铜屑。她踩湿滑碎石**滑进沟里**，膝盖磕在石头上，抓住一截伸来的手臂——**指节青绿、戴一只铜指套**＝归还台那个老头。他把她拉上堤，说「初五你就来了」，提起两只滴水桶沿水道**往城南走**；走出二十步回头看了她一眼，**看清了她的脸**，什么也没说就走了。→ **行踪第一次被看清**。
- 12:00 食堂：写下「初五，水涨。真的涨」「水里有铜屑」「他提两只桶往南走」「他看见我的脸了」；发现表上「取走多少」那一格是空的（取货条写的是**三十斤**）。
- 13:00 医棚后院·布罗：**「三十斤……不够。」**（比昨天清楚）→ 取货条上的量是**写给看条子的人看的**。老修女补出：布罗梦里那个音仍是「san」，昨天夜里尾音**往上挑**（「san——」）→「叁」单独一音 vs 接后字，两种写法并列，不划圈。
- 15:00 后院训练场·追踪者第五课 **「被看见了，就不用藏了」**：先问「昨天在哪儿」，她照实说了水道、被认出脸的事。追踪者：「你昨天把三条规矩一起犯了：不单独、不靠水边、不在同一个地方连续出现两次。」——但接着说 **「但你做对了一件：你没跟上去」**，因为她没跟，所以表上多出三行别人拿不到的证据。剑：恢复期第十五日**第三剑收得住**（风只灌半口袖口，人没晃，左肩不疼）。追踪者：「你的手记住的东西，用脚去记。」新课题：**「以后你的行踪要能被第二个人照着重走一遍，走出来一样，你才活得下去。」**
- 16:30 归还台：窗口**开着**（封窗木板拆了），柜台后是戴单只铜指套的老头独自在写，**桌上没有归还簿**，昨天那张告示也不在窗台。柜台内侧**桌沿新添一道竖划痕**→与告示落款、护身符铜牌划痕同形，凑成「一个人、同一套旧器具、签过三处」的签名链（**与「两条横一道竖」那族严格分开**）。
- 18:00 城南汤屋：胖摊主从她面前过时停了半步，低头看着她碗，说了第一句话——**「今天的水，别去碰。」**→他怎么知道她今天去了水道？这个城里知道初五要涨水的至少三个：布罗、摊主、老头。
- 19:00 城墙石阶·追踪者评表 **「过关了」**（陶师傅证铜、汤屋摊主证休沐、布罗证涨水——三人互不相识却各自独立画出一部分）。她终于说出憋了两天的事：**后院那片绿不是引东西给人看的，是引那只主动收集铜、四趾灰白小兽过来——是饵。**追踪者：「它知道你看见了？」她摇头。追踪者：「那就先别去找它。你今天被那个老头看见了。如果这城里有人在等一个人看见后院那片绿——」（未完）
- 21:30 宿舍·通讯石：互报平安第四日（「我今天膝盖磕破了，不严重」）。她第一次不问他问题，而是**请他帮忙**：口述那张四列表（初几／几点／谁来／谁能证明），请他凭她念的**重新画一遍**——「画得出来，就算数」。念到「谁来」那一列时手心出汗：她只知道「戴一只铜指套的老头」，不知道他姓什么、住哪、是否还守着那张窗口。纸末最后一行：**「初五。三十斤（布罗：不够）。水涨。桶往南。他看见我的脸。三十斤是写给谁看的。」**

## 线索与目标推进
- **三十斤是假数（新）**：布罗「三十斤……不够」＋初五实际涨水＋桶往南 → 取货条的量是给看条子的人看的，真实运走量另有数字。
- **「一道竖」签名链（新）**：告示落款／归还台桌沿／护身符铜牌背面，三处同形——一个人同一套旧器具签了三处；**与「两条横一道竖」那族严格分开**。
- **第二人独立复现（机制化）**：C级新人独立填表成功（布袋一格两人独立吻合）→追踪者评「过关」；第五课把同一要求从「表」扩到「行踪」；21:30 请宫磊口述复现＝把这件事变成两人协作。
- **初五交割目击**：水道涨水属实、水面浮铜屑、戴铜指套的老头提两只滴水桶往城南 → 与布罗「涨水不停」互相印证。
- **摊主立场需重估（新）**：从不出声的胖摊主第一次开口「今天的水，别去碰」——他如何得知她去了水道？沿用旧「洗清」结论不再成立。
- **库房钥匙**：告示「钥匙交代管，事后归还」→ 初五钥匙不在叁正清手上；叁正清整日告假，货仍在往外挪。
- **绿是饵的目标物（已说出口）**：艾莉亚向追踪者承认饵是给四趾灰白小兽的；追踪者要求**先别去找它**（约束必须体现）。
- **布罗梦话**：「san」尾音往上挑——单独一音 vs 接后字，两种写法并列。
- **反跟踪**：被公会内部的人（戴铜指套的老头）看清了脸＋被认出的场合本身敏感 → 身份暴露风险再升一级。
- **剑术恢复**：第三剑收得住，左肩不疼；今日右膝磕伤，次日暂缓高强度。
