# 2026-11-07（Day105）· 十一月初七，簿子不见了，铜片在回软

## 今日主线
- 05:00 宿舍：恢复期第十七日，右膝肿（老修女重缠布条），互报平安第六日。宫磊沉默**第四天**——她**不再追问**，改写成「我今天不问了」；纸上列三件事：①路线交给不认得的人画出来；②弄清初五夜钥匙过谁手；③布罗在哪（写完把纸翻过去）。
- 06:30 食堂：叁正清天没亮出城送旧箱；**归还台换了人坐窗口**（戴单只铜指套的老头）；**归还簿昨天傍晚被收走，谁收的不知道，执事长没吭声**；柜台上那只扣着的小木桶**也跟着不见了**，只剩一圈未干湿印。
- 08:00 公告栏：**没有新纸**——初五初六两张都没了，铜镇压纸下只剩一圈干净的方印（贴过又揭走）；库房门关着，缝下无光。
- 09:30 医棚后院：**布罗不见了**。被褥叠了、药碗倒扣、柜上留三十文和半包黄连。接走他的人「左手戴一只铜指套」，说话客气，还叫他「布罗先生」——是来**收回东西**的口吻；留话「东西我带走了，人留着也行」。老修女补刀：**他手上洗不掉的铜绿**。
- 10:30 **突发事件（坏事）** 归还台外三十步：叁正清**主动**走来停在她面前（距离是他选的），当面说：「初五夜钥匙在我手上」「归还簿那行是我签的」「我去库房门口是初四不是初五」；抬手把那只领了三年、工坊废后无人来收的铜指套脱给她看（铜已磨进肉），随后反问：**「你就是那天跟布罗说话的人？」**她没答也没否认，只点头转身走——**一否认就等于承认自己知道布罗、知道钥匙、知道库房**。纸上一行：「叁正清知道我是谁了。他没喊人。他只是让我知道，他知道。」**身份暴露由「被清点」升级为「被指认」。**
- 12:00 食堂：不走汤屋，留在公会；**把路线口述给 C 级新人画图**（她念、新人画，停顿必须写成「几盏香／几步／几个弯」的尺寸，不能写「一会儿」）。新人画完说「比我以为的远」——**对的，路比人以为的长**。第四课落地：光写给自己看不算数。
- 13:30 城南石槽：两只空桶已撤，水位再退一寸露暗红硬壳；沿水线朝城墙根方向走**二十步即停**，看见**一段翻过的土**（边被工具刮平、颜色更深），浮土下半片发黑旧铜——**记位置、未取、回填原样、剑鞘蹭净**。没有跟过去。
- 15:00 训练场：右膝仍肿，只站练。第四剑加到「**走三步再收一次**」——「光是站住没用，行踪是走出来的」。追踪者看新人画的路线图（一个停顿旁画着歪圈，写「这里水声大」），只说「**路开始长脚了**」，并警告「路长脚是好事，也是危险：它不再只属于你」。**第五课**：①每条路留一份别人能复现的版本；②**证据会被人撤走——簿子会没、证人会走、窗口会换人，所以路和纸比簿子活得久**。「证人会走，但走掉的人留过的话还在你纸上。」
- 16:30 汤屋后巷：**胖摊主缺席**，一个戴毡帽的陌生男子替他看摊，在擦一只**铜碗**（擦得很仔细）；她走过时那人**抬头看了她一眼**。她不停步、不搭话、径直离开。摊主昨天递铜片，是这只「擦铜碗的手」递的，还是更早的人？
- 18:00 汤屋晚市：摊主仍不在；端上来的碗底有一道被磨出来的亮痕。她**一个问题都没问出口**——昨天问一句差点掉饼，昨天问摊主被递铜片；今天学乖：不问。但心里排三件事——叁正清（知道她是谁、没喊人）、布罗（被接走、留三十文半包黄连）、陌生男子（替摊主擦铜碗、看了她一眼）。三件事她不敢连。
- 19:00 城墙石阶：追踪者验铜片，刮下绿层粉末发暗，指腹压过咬痕，说了一句：**「这不是它捡的铜，这是工坊的试料。」**——信标工坊做铜牌护颈扣时剩的边角料，**铜面上会留一面没磨平的印子**。铜片背面果然有一小块未磨平凸起。**护身符铜牌背面那道「一道竖」，是同一批模子。**追踪者：「**他们让你看见它咬过什么。这就是『让你看见』的意思。**」
- 21:30 宿舍·通讯石：**不再追问**，改说「昨天我教一个新人画我走的路，他画出来了。他说路比他以为的长」，请宫磊「画了就填上『停多久』，填不了也没事，我等你」。枕边多一样：新人画的路线图压在铜片下面；铜片在灯下**像正在往回缩**，她把它挪到窗台，次日要再验。

## 线索与目标推进
- **身份暴露升级（核心）**：叁正清当面反问「你就是那天跟布罗说话的人？」——她不能否认（否认即承认知情），只能不答。此人同时是「初五夜钥匙在谁手上」的**第一个人证**。
- **证人与明路同日被切断**：布罗被带走（留三十文、半包黄连、「东西我带走了，人留着也行」）；归还簿与小木桶被撤、窗口换人坐；汤屋摊主缺席由陌生男子顶替。
- **钥匙时间线**：初五夜钥匙在叁正清手上、归还簿那行是他签的、他去库房门口是**初四**——「初五夜去库房门口的人」空档仍在（是叁先生？）。
- **铜片=工坊试料边角**（背面未磨平凸印）→ 与护身符铜牌「一道竖」同批模子；「喂它铜」升级为「**标记**它」。与「两条横一道竖」那族仍严格分线。
- **新物证（未取、已记位）**：城南石槽边二十步内翻过的土、浮土下半片发黑旧铜。
- **方法论升级**：第二人独立复现第二次成立，且须写成尺寸（几盏香／几步／几个弯）；追踪者第五课「路和纸比簿子活得久」。
- **宫磊线**：沉默第四天，**本日不再追问**，改为协作邀请（请他填「停多久」）。
- **约束**：不接近小家伙；不跟城墙根；不单独再挖石槽；不与叁正清合并为叁先生。

## 🌙 Day105 摘要
阴，晨起细雨。石槽水位又退，桶没了，摊主也没了，布罗被人带走了，连归还簿都被收走。她手里少了两样东西：证人、明路。
然后叁正清站在了她面前三十步外，说出「初五夜钥匙在我手上」，摘下那只三年没人来收的铜指套给她看，然后问她：「你就是那天跟布罗说话的人？」
她没答，也没否认——一否认就等于承认。她只点了点头，走开。
傍晚追踪者验过那块被咬过的铜片，说：这不是它捡的铜，是工坊的试料，背面有没磨平的印子。和护身符铜牌是同一批模子。
夜里她不再问宫磊那个问题了。她改请他：如果画了，就把「停多久」填上；填不了也没事，我等你。
