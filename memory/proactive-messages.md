# 主动消息记录

## 2026-11-04 Day 102 主动消息

- 05:00 宿舍：恢复期第十四日，零绷带，左肩抬到最高也不疼；互报平安第三日（星辉石＋护身符都按了一下）；**护身符里那张折了四折的纸条今天终于打开——无字无落款，只有一个记号：两条横一道竖**（与包货纸纸角同族），而护身符铜牌背面划痕**只有一道竖**
- 06:30 食堂·执事助理两句话：**叁保管员今早告半日假**；**器物库房初五前不开库**（旧料一箱箱往外挪）；护身符铜牌是**老库信标工坊那批旧模子**做的
- 07:30 公会文书房：代字下压痕借斜光读出三个——**叁／記右半＋残笔／三点水**；老头一句「想看原始的，得去库房」
- 09:30 城墙旧箭垛外侧石阶：主线第一格，自己画旧运铜水道时间表（初几／几点／谁来＋南北两向）
- 10:30 **突发事件（出糗）** 炭线被勤务老伯当成乱涂地，罚扫半个时辰落叶；扫地时发现**石阶根部青砖缝里的淡绿旧水渍**，从后院墙根延到街口排水沟；老伯「年年这时候都有，后院老有人泼水扫地，说是洗地」
- 12:00 食堂：第一次写下 **铜→绿**，圈注「绿不是废料」
- 13:00 医棚后院·布罗：**「初五……涨水」**＋**「……不……不停」**；老修女说他夜夜梦话只有一个音，一直是「san」
- 15:00 训练场·追踪者第四课「谁能替你证明你没来过」：放松的手、五十步回扫×3；**恢复期第十四日首次正式出剑**（第二剑稳住）；追踪者「别用手，用脚」；复核时间表**划掉三处**＋**加第四列「谁能证明」**
- 16:30 归还台：**窗口封着、木板封严、柜台无人、老头也不在**，窗台一张告示被**铜镇纸**压着——归还簿、老头、窗口、告示四样一起消失
- 18:00 城南汤屋：初二休已成立，只喝汤不盯后门；宫磊连续两日无回音，她数了三次之后自己笑了——**石头不认人，不能等答案**
- 19:00 石阶复盘：追踪者说出那个字 **「饵」**——绿不是废料；**「你要找的是『谁在泼』，还是『泼给谁』？」**；艾莉亚脑中浮出小家伙，**没说出口**
- 21:30 宿舍通讯石：先说「我今天被罚扫了半个时辰的落叶」「你的护身符扣子松着吗」；报完全天发现，并替宫磊把答案先说了一半——**「铜最后变成了绿。绿不是废料。有人在后院摆一片铜绿，不是为了埋东西，是为了引东西过来。」** 随即收回：「这只是我猜的，你别当真。」初五就在明天。


## 2026-11-05 Day 103 主动消息

- 05:00 宿舍：恢复期第十五日，零绷带，左肩抬到最高不疼；互报平安第四日（星辉石＋护身符都按了一下）；追踪者把表还回来，右边多了一列，**四列：初几／几点／谁来／谁能证明**；她自己**凭记忆誊一份空表**——只抄结构不抄答案，准备找一个跟这件事毫无关系的人独立填（想到的是食堂那个C级新人）；护身符纸条归位（四折塞回最里层）；铜牌背面那道一道竖的划痕在灯下反光
- 06:30 公会食堂·执事助理：**叁保管员今天整天没来**（不是半日假）；器物库房照旧不开，「盘点未完，旧料还在往外挪」；旧料交给谁签收→「照规矩该叁本人签，他告假了，就**走代管**」→代管＝文书房「代」字底下那三个被刮的名字；老伯认出她就是昨天扫地的姑娘（「老伯说你扫地的时候对着地发呆，问你也不吭声」）
- 07:30 公告栏下：铜镇纸被挪到纸的左下角，**右下角的落款露了出来**——没有签名没有印，只有一个划痕，**一道竖**；告示正文抄全：「器物库房初五停用一日，盘点未完，旧料移出暂存；**钥匙交代管，事后归还**」；**三样不是一件事**——同族的是「两条横一道竖」那两样，这道竖是另一个人的签名
- 09:00 城南汤屋：把誊好的空表推给C级新人（「你昨天从哪条路走过来、几点、看见谁，就照你记得的写」），新人写完反问「这有什么用」，她笑着说「有用」→**第二个人画出来的表诞生**；「布袋被取走」一格上第一次看见两个互不相识的人写下的同一个意思（她的「每月初一」／新人的「初一，见过一次」）→这一格第一次有了「谁能证明」；随后到城北料行侧门外三十步远看一眼：侧门关着，门槛外一小片**新的还没干的水渍**
- 12:00 食堂午饭：纸上写下「初五，水涨。真的涨」「水里有铜屑」「他提两只桶往南走」「他看见我的脸了」；忽然发现自己表上「取走多少」那一格是空的，而取货条写的是**三十斤**——画了两只桶，写「一桶满水≈？」「三十斤……够吗？」；把碗一推，粥又凉透了
- 15:00 后院训练场·追踪者第五课「被看见了，就不用藏了」：先问「昨天在哪儿」，她照实说了；追踪者沉默比平时更久，「三条规矩一起犯了」之后却说**「但你做对了一件——你没跟上去」**；第三剑收得住，风只灌了半口袖口，人没晃，左肩不疼；「你的手记住的东西，用脚去记」；新课题：行踪要能被第二个人照着重走一遍
- 18:00 城南汤屋：胖摊主从她面前过时停了半步，低头看着她碗，**「今天的水，别去碰。」**——第一次跟她说话；碗里的汤一口没喝；这城里知道初五涨水的至少三个：布罗、摊主、还有那老头
- 21:00 宿舍·通讯石：报平安（「宫磊，我今天膝盖磕破了，不严重」），然后讲完一整天的水道、铜屑、老头、摊主、布罗——说完自己愣了一下：「……我说了好多。」然后换了个语气，很轻：**「宫磊，我今天求你一件事。」** 口述那张四列表，「你听着就行，不用记」，请他照着她念的**重新画一遍**——「画得出来，就算数」；念到「谁来」那一列时手心开始出汗：她只知道「戴一只铜指套的老头」，不知道他姓什么、住哪、是否还守着那张窗口
