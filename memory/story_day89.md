# Day89 · 2026-10-22 · 标准强度完全恢复日

清晨的窗棂里透进灰蓝色的天光，晨雾只剩薄薄一层纱，贴着窗台慢慢化。艾莉亚比闹钟早醒了一点点。她坐起身，先把手按在胸口的星辉石上——微温，稳定，昨夜没有异常跳动。她低头看着那块石头，忽然想起昨晚小家伙低下头、让她摸了两下头顶的那两秒，手心到现在还发痒。她在镜子前悄悄比了个手势：「今天一定行。」

九点，洞穴深处。幽蓝的光里，六块共鸣石排成一道弧形，冷气从石缝里渗出来，比昨天更凉。她深吸一口气，指尖拨响第一个音符——稳；第二个——顺；第三个……心跳快了半拍，指尖却没有滑。四个、五个、六个，一口气走完。收尾那一瞬，六块石同时亮起柔和的青光，胸口的热度只升了不到一度就稳住了。艾莉亚整个人靠在洞壁上喘气，手抖得厉害——不是怕，是那种终于把一件拖太久的事做完的抖。她翻开记录本写：「六音符全程无失误，光芒平稳，温度+0.8度，标准强度恢复确认。」写完还在末尾偷偷画了个小圈圈。

中午的训练场，地面被秋阳晒得发白。她把精钢短剑握热才上场，基础剑术Lv2的起手式接上风魔法的加速斩击，风刃贴着训练桩边缘削过去，木桩裂开一道整齐的口子。比昨天顺，可身体还慢半拍，重心得再沉一点。就在这时，小家伙没有像昨天那样在角落打瞌睡，而是慢悠悠走到训练场中央，在艾莉亚脚边停下来，尾巴卷着自己——然后低下头，用头顶轻轻蹭了蹭她的手。鳞片是温的、滑的、不躲的。艾莉亚差点把剑脱手，抖着手摸了两下它的头顶。小家伙慢慢退开，绕到训练场边上继续看着她。那两下，像是把它全身的信任都接了过来。

下午的酒馆，木桶酒味混着炖菜香。追踪者难得举了下杯：「封印已经完全适应标准强度，按原计划推进就行。」然后她压低声音问了一句昨晚洞穴里有没有听到什么。艾莉亚这才想起早上收尾时深处那一声极轻的「咔」。追踪者从皮袋里摸出一小片旧金属片放在桌上——从共鸣石底座内侧剥下来的，刻着三道交叉的弧线，末端一个小缺口。「这是老库信标网络的老记号。」追踪者第一次沉下脸，「这套记号在你来之前，已经被人用过很多次。别声张。」艾莉亚握杯的手一僵：「……不是只有老库在收这些东西？」「不。」追踪者盯着那片金属，「至少还有第二个人，在用同一套记号。」窗外秋云压得很低，酒馆里的火把噼啪响了一声。

夜里，宿舍安静得只剩风声。艾莉亚躺在床上把通讯石捧在手心，星辉石贴着胸口暖着。「宫磊——」声音里全是藏不住的雀跃，「今天六个音符我一口气弹完了！一次都没错！六块共鸣石一起亮起来的时候，我整个人都愣住了。」翻了个身把脸埋进枕头，又抬起来继续说，「还有还有，比这个更厉害的——训练的时候小家伙自己走过来，低下头让我摸它的头顶！它没躲！以前它连靠近我都会躲的。」说着声音轻了下去。窗外的风把云推得很低，秋意从缝里钻进来。她把第二个人用老记号的事悄悄压在心里，没说出口，只觉得掌心的通讯石也微微一暖，像小小的回应。

这一天，最亮的是六块石头同时亮起的那层青光，最暗的是酒馆桌上那片刻着旧记号的金属。两条线在同一只手里握着——一头是终于敢被信任的温热，一头是不知道还有谁在暗处数着同一套记号的凉。艾莉亚把记录本合上，吹熄了灯。她想，今天的好消息是真的，那个「咔」也是真的。明天，还是一样早醒，一样先把手放在心口。
