# エルデア大陆 — 世界观（基础设定，不随故事推进变化）

> 艾莉亚生活的异世界基础设定。此处内容为世界常量，角色扮演中不可改变。

## 一、世界概览

### 大陆名：エルデア（Eldea）
- **时代背景**：中世纪末期，王权与公会并立的城邦制社会
- **魔法体系**：魔法能力与生俱来，六大元素魔法——火、水、风、土、光、暗
- **科技水平**：冷兵器时代，作坊手工业为主，无火药、无工业革命
- **已知大陆地理分区**：
  - 中央王国领地：城镇与村庄集中分布，冒险者公会网覆盖
  - 东部边境森林 → 延伸至未开拓蛮荒地带
  - 西部商业都市圈：贸易繁荣，流通畅通
  - 南部农耕平原：粮仓地带，物产丰富
  - 北部边境（→ 后续设定参考「未解锁区域」）

### 种族设定（固定列表）
| 种族 | 特性 | 主要分布 |
|------|------|----------|
| 人类 | 平均寿命80岁，适应性最强 | 全大陆，人口最多 |
| 精灵 | 长寿（300-500年），擅长魔法与弓箭 | 森林地带 |
| 矮人 | 寿命200年，锻造/工程大师 | 矿山/山岳地区 |
| 兽人 | 体格强壮，部分亚种有特殊感官 | 边境地区 |
| 龙族 | 传说级存在，可化身人形 | 极少数，隐居各处 |

### 重要势力（固定列表）
- **冒险者公会总盟**：全大陆冒险者的最高管理机构
- **王国**：大陆中央的人类王国
- **魔物生态圈**：自然存在的野生魔物分布，非统一势力

## 二、冒险者公会制度（固定设定）

### 定位
大陆各地城镇设有冒险者公会，负责管理任务委托、冒险者等级评定、信息流通。公会之间信息互通。

### 冒险者等级体系（固定）
| 等级 | 名称 | 晋升基本要求 |
|------|------|-------------|
| D | 初级 | 注册即获得 |
| C | 中级 | 完成5个D级任务 |
| B | 高级 | 完成10个C级任务 + 特殊贡献任务 |
| A | 精英 | 完成5个B级任务 + 大陆公认贡献 |
| S | 传说 | 特殊评定，极少有人达到 |

### 任务分类（固定）
| 类型 | 说明 |
|------|------|
| 采集 | 药草/矿石/素材采集，难度最低 |
| 讨伐 | 魔物清理、指定目标讨伐 |
| 探索 | 新区域/遗迹调查 |
| 护卫 | 商队/贵族的护送和保镖 |
| 护送 | 物资/人员的安全运输 |
| 特殊 | 情报收集、道具制作、研究协助 |
| 紧急 | 突发的灾难、大规模魔物袭击 |

### 公会内部岗位（固定）
- **公会会长**：公会最高负责人
- **接待员**：任务受理、信息传递
- **情报员**：负责情报收集和价格评估

## 三、世界地理（固定地形/区域名称）

### 已开放区域
- **中央王国**：人类社会核心区域，各城镇分布

- **商业城市圈**：西部的贸易中心

- **石柱群地下通道**：石柱群森林下方的古代通道网络，连接信标核心与塞尼卡档案馆，危险且昏暗
- **塞尼卡档案馆**：王立考古学院下属档案设施，塞拉斯在此查阅星廊守护者历史和七工匠记录
- **核心阵列**：王都地下皇家宫殿地基下方的先民设施，五根石柱围成五边形，中央为共振之桥，用于跨世界通讯
- **共振之桥**：核心阵列中央的先民装置，需要五钥+石芯+共鸣器激活，可开启跨世界通道
- **西门外交界岔路口（收旧货摊一带）**：城门守卫记录出货的地方，旧工坊废铜件在此被收旧货人布罗转手，经西门出城

- **西门围墙豁口**：城墙破损缺口，通向城外官道，旧磨坊出城的拖痕即由此延伸出去
- **城南铜匠铺**：城中收熔旧铜的铺子，老板姓陶、一只眼蒙白翳；三个月前熔过一批旧工坊铜件，来料以旧斧与铁屑抵账，留有旧单

- **城门临时医棚**：城门边的临时伤棚，公会老修女在此接手布罗的伤
- **公会器物库房与登记台**：公会内院北头的器物库房；门外有一张一尺长的旧木案登记台，厚册摊开放着（两块鹅卵石压着防风翻页），钥匙登记簿等器物册在此公开可查，平时无人看
- **城南汤屋**：城南蒸汽腾腾的汤屋摊，摊主天天往公会后门送热汤，是观察公会后门日常人员往来的位置

## 四、角色性格成长体系（事件驱动型）

> 艾莉亚的性格没有预设轨迹。她因经历而改变——**先有事件，后有性格变化**。
> 当某个重大事件发生时，评估是否需要对性格进行调整。不主动创造事件来迫使她改变。

### 核心原则

1. **事件驱动**：性格变化不是按等级自动升级的，而是被经历触发的
2. **不预设路线**：同一个事件可以让她变得更谨慎，也可以让她变得更勇敢，取决于当时的状态和事件的性质
3. **可逆**：性格可以反复，人不是一直向前进步的
4. **微调为主**：大部分事件只会微调性格的一个侧面（比如「变得对陌生人更警惕了」），不需要全盘改写
5. **自然积累**：日常小事的积累也会产生缓慢的性格变化，不需要次次都靠「大事件」

### 触发性格评估的事件类型

| 事件类型 | 示例 | 可能的影响 |
|---------|------|-----------|
| 被骗/背叛 | 任务委托人设局、同伴背刺 | 警惕性↑，信任度↓ |
| 失去/失败 | 任务失败、某人受伤 | 谨慎↑，自我怀疑/奋发 |
| 成功/突破 | 独立完成高难度任务 | 自信↑，依赖性↓ |
| 感情波动 | 和宫磊的对话触动了内心 | 开放度↑/防御↑ |
| 生存危机 | 差点死掉、遭遇远超等级的威胁 | 恐惧/斗志 |
| 日常积累 | 反复做同一类事后变得熟练 | 从容度↑ |

### 感情线的性格变化

感情进度（progress_pct）可以作为参考指标，但不绑定性格。艾莉亚在感情上的成长也是事件驱动的——**每一次和宫磊的深入对话都是一次小型事件**，可能改变她在这段关系中的表现方式。

当前感情表现应通过 state.json 的 today_mood 和 mood_reason 来体现，而不是套公式。

### 记录方式

当性格发生变化时：
1. 在 memory/YYYY-MM-DD.md 的当日记录中注明
2. 如果变化显著，更新 state.json 中反映性格倾向的字段
3. **不修改 world.md 的性格成长体系**——此文件只定义框架，不记录具体变化

## 旧运铜水道与废弃取料口（地图未标·已实地确认 Day100）

位置：城南旧货市再往南，过塌了半边的石桥，河汊分岔处。水道不宽，两边旧石砌，青苔满缝，**现用地图上无连线**。水道边三个废弃取料口：
- 第一个、第二个：石阶塌半边，洞口挂锈死的铁栅栏，栅栏结厚绿。
- **第三个：石阶完整，栅栏不在洞口——是被细齿锯开的**，断面上有新的锯纹；锯开的那一截栅栏就靠在旁边石阶上，**锯面朝上**（不像要藏，更像带不走或懒得带）。

水情与工序（Day100 遇挑水老头所得）：旧水道早已不运铜，只运水。**城北几家泡铜的料行，铜要先从这条水上过一遍，水面那层薄绿膜就是铜锈**，铜锈被带回去兑药引子。故：
- **铜绿（铜锈）＝旧运铜水道的水带出来的**。公会后院墙根石缝里那片指甲盖大的铜绿，是有人把水道的水带回后院所致，不是自然掉落。
- 铜绿次日不见，配合追踪者判断「它不是掉在那儿的，是被叼过去的」＋小家伙窝底蹭碎的铜绿碎屑 → **小家伙在收集铜**，其巢穴可能就在水道某个取料口。

风险：老头看见了艾莉亚的脸（普通人但记住了「一个姑娘站在水道边」）→ 追踪者判定**不得再赴此线第二次**，实地探查中止，转查人（城南铜匠铺独眼陶姓铜匠、文书房当值名册）。

**水路方向改写（Day101）**：此前判断为「城北料行取水道的水泡铜」，追踪者 Day101 定论——**水不是往北运的，是有人把城北的水往城南的公会后院运**。依据：料行侧门出来的归还台女助手扛一只盖布小木桶，桶沿滴水、湿痕往南拖；城北到城南最快的就是旧运铜水道。故公会后院墙根那片铜绿**不是「沾上」，是「浇上去」的成品**，它第二天消失也不是自己散的。Day102 功课：把水路的时间对出来（初几、几点、谁来、桶往哪走），表自己画。

**地面物证（Day102）**：罚扫时在**城墙旧箭垛外侧石阶根部的青砖缝**里看见一层很淡的旧水渍，颜色是绿的，沿砖缝连成一条断断续续的线，**从后院墙根那个方向一直延到街口的排水沟**。公会勤务老伯说：「年年这时候都有，后院老有人泼水扫地，说是洗地。」→ 水道第一次有了地面上的印证；这条线的南段起点正是城墙石阶根部，方向为**城北→城南**。她当时差点把它扫进柴垛。

**初五＝连续供水（Day102）**：布罗在医棚挤出「初五……涨水」＋半句「……不……不停」——初五不是一桶一桶往回扛，是水道涨水、连续供。后院那片绿不是泼一次，是那天泼了一整段。

**初五实况（Day103 目击）**：十一月初五上午，**第三个取料口外水真的在涨**——铜锈色的水一段一段往上漫，把岸边碎石泡成暗红，水面浮着一层细铜屑，随波纹一圈一圈散开。观者：艾莉亚（单人在堤上，**只看、不进、不跟**）。同场人：**归还台当值老头**从城北方向踩浅水下来，把滑进沟里的她拉上堤，说「初五你就来了」，随即**提两只滴水桶沿水道往城南走**——桶里装的是什么、卸在何处，未知。城北料行侧门外门槛有**一片新的还没干的水渍**（同日 09:00 远看）。

## 城北料行「叁记」铺面（只看不进·Day101 确认）

位于城北，两扇厚木板门，门上一块旧木牌写着「叁记」两字，字写得规矩（与取货条上同一路字）；门口挂厚毡帘子，进出的人不多，**出来的人手上都有绿**（一个袖口沾着，一个手背上一道绿的印子）。侧门可通后面巷子，女助手从此门扛桶出来（桶沿滴水）。艾莉亚只在**斜对面巷口阴影里**观察，未进店。

## 城南铜匠铺（明路·Day101 实地确认）

城南靠河那条街上，铺子窄长，门口挂几十片铜片，风一吹全在响。**后院**是三层木架，铜片一片片斜靠着，霜气一蒸表面浮起雾状的绿；风从墙豁口灌进来，可掀动架下压着的纸。铺主陶师傅独眼，一只眼蒙着发黑的皮。

## 归还台（公会公告栏下·窗口当值人可变·Day101）

窗口后的当值者会换：Day98/99/100 是归还台年轻女助手，**Day101 换成戴帽压低的老头**，归还簿合着（前日同一位置是摊开的）。归还台只碰纸墨，不碰铜。

**Day102（十一月初四）**：**窗口木板封严、柜台无人、当值老头也不在**；窗台上压着一张新的告示纸，边角用一枚**铜镇纸**压着。归还簿、老头、窗口、告示四样一起消失，只留下一张被镇纸压住的纸。同日**器物库房初五之前不开库**——**初五前归还台与器物库房同一天关门**。

**Day103（十一月初五）**：封窗木板**拆除，窗口重新打开**；柜台后是戴单只铜指套的老头独自在写，**桌上没有归还簿**，昨天的告示也不在窗台上。柜台内侧桌沿**新添一道斜竖划痕**——与初五告示落款、护身符铜牌背面划痕同形（**一个人、同一套旧器具、签过三处**）。初五公告栏告示正文：「器物库房初五停用一日，盘点未完，旧料移出暂存；**钥匙交代管，事后归还**。」落款无签名无印，只有一道竖；铜镇纸被挪到纸的左下角后露出，**镇纸底下的铜面比别处绿得深**。

## 城南汤屋后门巷（已确认·危险度最高）

Day99（2026-11-01）实地确认：后门夹在汤屋侧墙与隔壁旧屋之间，最窄处只容一人侧身。每月初一清早开一次，由归还台年轻女助手开门、抱出布袋（袋口麻绳绕三圈），叁正清在巷口另一头接袋后往北走。清早巷内无人——摊主会提前腾空大锅、扣死门板清巷配合。

## 册部留档架（公会文书房西墙·最下一层·木匣第三格·Day111 首次进入）
闭册后底册已被收回，抄件成为孤本；册部留档架是唯一能合法看见**原页**的入口。位置：公会文书房**西墙最下一层**，叁〇七批留档在**木匣第三格**，匣上贴**黄纸封条**，封条破了即等于「她碰过」。**规矩：不碰封条**——请文书房当值老头**代为开封并当场记录**开匣时刻与在场二人（追踪者：这就是第三方）。Day111 留档原页实况：叁〇七批**领用栏是真字「壹」**（旧墨、笔锋与同页一致），**左边领用人栏另有一道笔迹残笔——一道竖，上端带钩、比牌背刻痕更细、位置更靠左**；**挖补块为不规则方形、跨了领用与领用人两格**。判定：对手保的不是「壹」，是**那道签名**（签名指向人，空白只指向「没写过」）。开匣后新封条**两人签名**，抄件与图分开放置。
